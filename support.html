Support

Questions, problems or ideas: write to kobar.sept@gmail.com. Please include your macOS version and your TurboShelf version.

Where is TurboShelf?

TurboShelf lives in the menu bar. It has no Dock icon. Press ⌥ Space in any app to open it, or click the menu bar icon and choose Open TurboShelf.

Return does not paste

Pasting into another app needs the Accessibility permission. The Save Copy and Link shortcuts need it too. Click the menu bar icon, choose Set Up Save Copy…, then Continue. macOS asks for permission. Choose Open System Settings and turn on TurboShelf in Privacy & Security → Accessibility (on macOS 27: Device Control and Data Access). If you closed the macOS dialog, choose Open System Settings in the TurboShelf window. When TurboShelf shows Access confirmed, press ⌥ Space in the app where you want to paste.

If TurboShelf is already turned on and access is still not confirmed, or Return still does not paste, quit TurboShelf from its menu bar menu and open it again from the Applications folder. Without the permission, Return does not paste, and ⌘ Return copies the item. Then paste it yourself with ⌘ V.

How do I save items?

Drag text, images or files onto the TurboShelf panel. In most apps you can also select text and choose Services → Save Copy to TurboShelf from the app menu. The + menu in the panel saves new text or links a file or folder. With the permission above, press ⌥ C to save the selection in any app, or press ⌥ L in Finder to link the selected files and folders.

When you save or link items in your Desktop, Documents or Downloads folder with ⌥ C or ⌥ L, macOS can ask once whether TurboShelf can access that folder. The dialog says: “TurboShelf saves a copy of, or a link to, the files and folders you choose with Save Copy or Link.” If you chose Don’t Allow, drag the items onto the panel to save a copy, or use + → Link File… or Link Folder… in the panel. Or turn on TurboShelf in System Settings → Privacy & Security → Files & Folders.

What does the Free limit count?

Free keeps up to 25 saved items with every feature. Files in a linked folder do not count. Saving the same item again does not count. When you save item 26, TurboShelf offers TurboShelf Pro. Your existing items always stay usable.

Restore TurboShelf Pro

Click the menu bar icon and choose Restore Purchases. The TurboShelf Pro window also has Restore Purchases. Use the same Apple Account that bought TurboShelf Pro.

Change the keyboard shortcuts

Click the menu bar icon and choose Keyboard Shortcuts….

Move items from the earlier TurboShelf

If you used the earlier, directly downloaded TurboShelf, quit it first. Then click the menu bar icon and choose Import Library from Previous TurboShelf…. Choose the folder ~/Library/Application Support/com.shelf.prototype (press ⇧⌘G to type the path) and click Import. If you have linked files, allow access to the folder that contains them. The earlier library is only read, and you can import again without duplicates.

Remove TurboShelf and its data

Quit TurboShelf, delete the app, and delete its folder ~/Library/Containers/com.kobars.turboshelf. Removing TurboShelf never deletes your original files.
